# JARVIS PRO 🤖

مساعد ذكاء اصطناعي متكامل — بناء مواقع + بحث ذكي + أدوات.

## التثبيت

```bash
pip install -r requirements.txt
```

## الإعداد

```bash
export ANTHROPIC_API_KEY="your-api-key-here"
```

## التشغيل

```bash
# النسخة المتكاملة (مواقع + بحث + أدوات)
python jarvis_pro.py

# النسخة الأساسية (محادثة فقط)
python jarvis.py

# النسخة مع أدوات بسيطة
python jarvis_with_tools.py
```

---

## قدرات Jarvis PRO

### 🌐 بناء مواقع ويب
اطلب بالعربي وسيبني لك الموقع مباشرة:

```
أنت: ابني لي موقع portfolio احترافي باللغة العربية
أنت: اصنع لي متجر إلكتروني لبيع الملابس
أنت: ابني صفحة هبوط لتطبيق ذكاء اصطناعي
أنت: اصنع لي موقع بيو روابط مثل Linktree
```

الموقع يُحفظ في مجلد `jarvis_projects/` ويمكنك فتحه في أي متصفح.

### 🔍 بحث ذكي على الإنترنت
```
أنت: ابحث عن أحدث أخبار الذكاء الاصطناعي
أنت: ابحث عن أفضل فريمووركس Python 2025
أنت: وش سعر Bitcoin الحين؟
```

### 🛠️ أدوات متعددة
```
أنت: كم الساعة الحين؟
أنت: احسب لي 2 أس 10
أنت: احفظ ملاحظة: اجتماع غداً الساعة 9
أنت: عرض مشاريعي         ← يعرض كل المواقع المبنية
```

## إضافة أدوات جديدة

أضف في قائمة `TOOLS`:
```python
{
    "name": "my_tool",
    "description": "ماذا تفعل هذه الأداة",
    "input_schema": {
        "type": "object",
        "properties": {
            "param": {"type": "string", "description": "وصف"}
        },
        "required": ["param"]
    }
}
```

ثم أضف في `execute_tool()`:
```python
if name == "my_tool":
    return f"النتيجة: {inp['param']}"
```
